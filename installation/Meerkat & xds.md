# Installation of Meerkat and xds

## Meerkat and Xds work collaboratively in a similar manner to how DIALS compliments Mdx2. 

### Meerkat 

<details>

<summary>Meerkat</summary>
- [Meerkat]([url](https://github.com/aglie/meerkat))  is a python library developed by Arkadiy Simonov. It performs reciprocal space reconstruction from single crystal XRD data. 
- Meerkat can be installed using a package manager such as pip:
  
  ```
pip install meerkat
```

</details> 


<details>

<summary>XDS</summary>
- XDS is needed to run meerkat as it generates an orientation matrix for 
  
  ```
pip install meerkat
```

</details>
